# Club crests (Verbandsliga Süd)

Synced from [tfvh.de](https://tfvh.de/index.php/verbandsliga-sued) into this folder.

```bash
pnpm sync:crests
```

That downloads hi-res logos and regenerates `src/lib/tfvh/crests.generated.ts`.
Commit both the images and the generated file so OBS/production never hotlinks TFVH.
