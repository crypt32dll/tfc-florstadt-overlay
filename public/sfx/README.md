# Overlay SFX

Default: Web Audio tones in the OBS browser source (`useOverlaySfx`).

Optional file overrides — drop short clips here and they are preferred when present:

| File           | Event            |
| -------------- | ---------------- |
| `goal.mp3`     | Goal scored      |
| `set.mp3`      | Set finished     |
| `switch.mp3`   | Screen / test    |

Keep files short (&lt;1s) and reasonably loud; Control volume still applies.
